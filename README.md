## Overview
This repository contains my contribution to the "Security Hardening Checklist for a Healthcare Clinic" project. As Group Lead, I used Wireshark to capture and analyze network traffic, and defined 5 detection/alert rules relevant to a healthcare clinic environment.

## What's Included
- 5 network detection/alert rules (with detection logic, risk, and response steps)
- Sample log-review report
- Wireshark traffic capture screenshot
- Full report: see `SecurityChecklist_GroupLead.docx`

## Detection Rules Summary
1. Plaintext Login Credentials
2. Brute-Force Login Attempts
3. Off-Hours System Access
4. Unusual Outbound Traffic
5. Medical Device Communicating on an Unexpected Port

## Conclusion
These detection rules and monitoring practices help the clinic identify security threats early and respond quickly, protecting patient data and critical systems.
